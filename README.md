# Tcl Simple Scripts

A collection of small, practical Tcl scripts for automation, configuration handling, and scripting demonstrations.

## Samples

| Sample | Description |
|---|---|
| [`proxy_handler/`](proxy_handler/) | Reads proxy and credential settings from `.netrc`, `.curlrc`, and `.wgetrc` style files. |

## Purpose

This repository is a lightweight Tcl scripting portfolio and reference collection. The examples are intentionally small, readable, and practical.

## Requirements

- Tcl 8.6 or newer

## Running a sample

```bash
cd proxy_handler
tclsh gproxyrc.tcl
```
